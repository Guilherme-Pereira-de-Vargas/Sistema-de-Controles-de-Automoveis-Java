# Sistema de Controle de Automóveis em Java

Sistema de console para gerenciamento de uma revenda de veículos, desenvolvido em Java. Permite cadastrar, pesquisar, alterar e excluir clientes, funcionários e veículos, incluindo carros e motos.

O projeto aplica conceitos de programação orientada a objetos, como herança, encapsulamento e sobrescrita de métodos. Os registros são mantidos em memória durante a execução, com menus de texto para acessar as operações.
